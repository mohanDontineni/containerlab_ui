# Code of conduct

We are committed to a welcoming, harassment-free community. Be respectful, assume good intent, give actionable technical feedback, and welcome contributors regardless of background or experience. Harassment, discrimination, threats, doxxing, and sustained disruption are not acceptable.

Report conduct concerns privately through the repository owner's GitHub profile or security-reporting channel. Maintainers may edit or remove content and temporarily or permanently restrict participation when necessary to protect the community.
